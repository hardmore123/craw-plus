# 参考网站与完成度 · 交接说明

本目录汇总**抓哪些网站**（网址）和**抓到什么程度**（完成度），供交接方快速判断现状、决定下一步。
口径以不同时点的梳理为准，互相参照即可；最权威的「能否跑全量」判定看 `逐站状态.md`（来自真实小样实测）。

## 2. 网址在哪看
- **最全、最新**：`站点清单_含网址.csv`（260 站，直接从库导出，与代码里 `site.base_url` 一致）。
- 带任务维度（哪个站做价格还是认证、对应 schema/adapter）：`爬取进度_四维梳理_20260924.csv` 的「网址 / 站点code」列。
- 代码内同一数据：`01_项目代码/overseas/regions_auto.py`（区域→站点注册）与各 `overseas/sites/<code>/adapter.py` 的 `base_url`。

## 3. 完成度总览

### 3.1 零售线「能否支撑全量」（真实小样实测，最硬的口径，见 `逐站状态.md`）
124 站实测：**READY 27 / PARTIAL 31 / FAIL 51 / NO_SAMPLE 15**；另 135 份 spec 本轮未实测。
READY 名单与各站缺口原因见 `逐站状态.md` 与 `../04_待完善与未实现.md`。

### 3.2 四维梳理口径（`爬取进度_四维梳理_20260924.csv`，363 行，含三条线）
- 任务类型：价格+网评 224、认证+评测 73、Spec 66。
- 是否已抓取：✅ 完成 65、🟡 部分 22、❌ 未完成 249、➖ 缺 URL 5。
- 是否全量完成：✅ 完成 48、🟡 部分 13、❌ 未完成 275（另有标注「冲突行/重复行」各 12/10 需人工并一下）。
- 区域：欧洲线 186、南美线 95、北美线合计约 75、日本线 7。

> 两个口径差异原因：四维梳理是 9-24 的人工全量盘点（含认证/评测/未开发站），`逐站状态.md` 是后续用程序对**有 spec 的零售站**跑小样的结果。
> 「某站能不能跑全量」以 `逐站状态.md` 为准；「整体还有多少站没做/被反爬」看四维梳理。

### 3.3 主库实际沉淀的数据（`数据覆盖_按国家.md`）
158 个站有数据、39 个国家；有价商品 11,134、评价 95,207、官网 SPEC 39 品牌 1,098 系列。

## 4. 没做完的大头（详见 `../04_待完善与未实现.md`）
- 约 21 站被反爬（Akamai/PerimeterX/Cloudflare/DataDome），需目标国住宅 IP；10 站只在英国出口可达，spec 待重探。
- 南美各国型号清单混入别国型号码，会导致大量「搜索结果为空」，需按国核对。
- 俄罗斯站全部需俄罗斯 IP。
- 卖点线、榜单线表已建但数据为 0；媒体评测仅 148 篇。

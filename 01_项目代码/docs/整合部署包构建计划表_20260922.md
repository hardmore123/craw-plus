## 二、目标结构（单一根 + 共享库唯一）

```
海外数据爬取_部署包/
├── README.md                      ← 总入口（5 分钟上手）
├── DEPLOY.md                      ← 部署与运维（含定时任务）
├── STATUS.md                      ← 各线现状/能力/限制（诚实版）
├── CHANGELOG.md                   ← 本包相对上一版的变化
├── requirements.txt / pyproject.toml
│
├── overseas/                      ★共享库唯一副本（含全部子目录）
│   ├── sites/                     （80 站适配器 + 13 schema）
│   ├── api/                       （后端接口 + 前端静态）
│   ├── dict/                      （翻译词典）
│   └── *.py                       （引擎与基础设施）
├── scripts/                       ★全部脚本唯一副本（63 个）
├── cli 入口：python -m overseas.cli
│
├── specs/                         ← 契约与规范
│   ├── AdapterSpec_schema规范.md
│   ├── RetailSpec_schema规范.md
│   └── retail_specs/*.retail.json  （17 份）
├── skills/                        ← 两个 skill（spec/retail schema-gen）
│
├── docs/                          ← 文档（方法/指标/验收/排期）
├── data/                          ← 数据产物（按线分目录，只放最新）
│   ├── jp/  ca/  mx/  sa/  eu/
│   └── db/                        ← 最新数据库 + 备份
└── deploy/                        ← 部署资产（systemd / Windows 任务）
```

**关键设计**：`overseas/` 与 `scripts/` **全局唯一**（不再按国家复制），
各线只分 `data/` 产物 —— 从结构上消除重复与漂移。

## 四、日本线价格曲线：可行性结论（本次重点）

### 4.1 结论：**可以，且基础设施已就绪**

| 能力 | 现状 | 位置 |
|---|---|---|
| 按渠道存价 | ✅ 已有 | 表 `price_shop_snapshot(product_id, shop, price, is_lowest, captured_at)` |
| 只增不改（天然时序） | ✅ 设计如此 | `db.add_shop_prices()` 仅 INSERT |
| 周度聚合查询 | ✅ 已有 | `db.weekly_price_series(site, weeks_back)` → 产品×渠道×周 |
| 周度采集调度 | ✅ 已有 | `scripts/weekly_kakaku_price.py` |
| 曲线生成（网页） | ✅ 已有 | `gen_jp_price_trend_html.py` |
| 曲线生成（Excel 原生图表） | ✅ 已有 | `gen_jp_price_trend_xlsx.py` |

### 4.2 渠道数（实测 8 家）

```
ビックカメラ.com · Joshin · ヤマダウェブコム · ノジマオンライン
ケーズデンキ · エディオンネットショップ · Amazon · ヨドバシ.com
```

### 4.3 ★当前唯一缺口：**只有 1 个时间点**

```
price_shop_snapshot: 1441 行，全部 captured_at = 2026-09-09
→ 8 渠道 × 284 产品，但"周次=1" ⇒ 画不出曲线（单点无线）
```

**因此曲线的前提是"开始按周采集并积累"**，而非改代码。

### 4.4 已知缺陷（需修，不影响建包）

| 缺陷 | 说明 | 影响 |
|---|---|---|
| **周键口径不一致** | `weekly_kakaku_price.py` 用 ISO 周（`2026-W37`）；`db.weekly_price_series` 用 `strftime('%Y-W%W')`（`2026-W36`）→ **恒定差 1 周** | 两者若做 join 会错位；单独用无碍 |

## 六、风险与注意

| 风险 | 说明 | 应对 |
|---|---|---|
| 建包时工作区**有并发会话**在改代码 | 可能拷到中间态 | 建包前记录文件时间戳；建包后跑自检 |
| 数据库正被写入（有 `-wal`） | 直接拷可能不一致 | 用 SQLite backup API 或先停写 |
| 数据体积大 | 网评 CSV 达 2.3MB×2、DB 19MB | 只取最新 + 可选项排除 bulk |
| 敏感凭据 | `data/session/*.state.json` 含 cookie | **排除出包**，仅留 `.gitkeep` 说明 |
| 浏览器 profile | `data/browser_profile/` 体积大且含登录态 | **排除出包** |

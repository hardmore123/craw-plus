## 3. 怎么跑（可复制命令）

> 环境：Windows PowerShell + Python 3.12（`py -3.12`）。命令用相对路径，均在项目根执行。
> PowerShell 不支持 heredoc；中文在 execute 会话可能显示乱码但文件本身是 UTF-8。

### 3.1 SPEC 线（发现 + 抓规格）

```powershell
# 用已存 schema 抓某站全站 SPEC（sandbox 库，勿污染正式库）
$env:OVERSEAS_DB = "data/sandbox_x.db"
py -3.12 -m overseas.cli spec-crawl --schema docs/specs/philips_ca.spec.json

# skill 探测 / 校验（接新站）
py -3.12 .kiro/skills/spec-schema-gen/probe.py --entry "<入口URL>" --code x_ca --expect-models N
py -3.12 .kiro/skills/spec-schema-gen/probe.py --verify data/schema_drafts/x.spec.json
py -3.12 .kiro/skills/spec-schema-gen/selfcheck.py    # 骨架健康自检
```

### 3.2 零售线（墨西哥，当前唯一可抓国家）

```powershell
# 墨西哥某站抓价格+网评（评价上限默认 100，可 --max-reviews 覆盖）
py -3.12 scripts/mx_line.py retail --spec docs/retail_specs/liverpool_mx.retail.json --limit-models 20

# 加拿大/美国线（需线路；--spec 提供后评价翻页按 spec 执行）
py -3.12 scripts/crawl_ca_retail.py --region ca --models-csv data/加拿大/SPEC_型号汇总_ca.csv --spec docs/retail_specs/amazon_ca.retail.json --max-reviews 100

# 从已有 schema.json 批量生成 RetailSpec
py -3.12 scripts/build_retail_specs.py
```

### 3.3 评价上限怎么改（R1-5，四级优先级）

```
CLI --max-reviews  >  spec.paginate.reviews.max_reviews  >  环境变量 OVERSEAS_MAX_REVIEWS  >  默认 100
```
改默认值只动 `overseas/retail_spec.py` 的 `DEFAULT_MAX_REVIEWS`。

## 6. 必须知道的坑（血泪）

**坑1：`.kiro/` 与 `__init__.py` 的 gitignore 陷阱**
`.gitignore` 的 `_*.py` 规则会误伤 `__init__.py`；`.kiro/` 整段忽略会漏掉 skill。
现已改为 `.kiro/*` + `!.kiro/skills/`、并对 `__init__.py` 加白名单。
**换机拉代码若报 `cannot import SiteRegistry`，先查 `__init__.py` 是否都在。**

**坑2：零售线红线是「匹配准确率」不是「找全率」**
SPEC 线怕抓不全，零售线怕**抓错**——把 55 寸的价格记到 65 寸头上、把支架评价当电视评价。
`match.on_no_match` 必须 `skip`（校验强制），**禁止改 `first` 提高覆盖率**。
历史真实 bug：搜 75U6SV 主干匹配命中了 55U6SV（同款不同尺寸），已在 match_product 加
尺寸一致性拒绝。

**坑3：`or` 陷阱吞掉 0 值**
`int(cfg.get("start") or 1)` 在 start=0 时会被替换成 1。offset/页号这类合法值含 0 的字段，
必须显式判 `None`。（R1-4 踩过。）

**坑4：JS 片段的三层转义**
JS 片段嵌在 Python raw string 里，`new RegExp(字符串)` 的反斜杠要按 Python 字面→JS 字符串
→正则数清。改片段后必须 `node --check` + 对真实 aria-label 自测。（P0-1 相关，SPEC 线。）

**坑5：clean_url 去尾斜杠**
零售/SPEC 的 URL 抽取都过 clean_url，它去查询串和末尾一个斜杠。model_url_regex 若把型号
放 URL 最末段，不能硬要求结尾 `/`，否则发现 0 个。

**坑6：PowerShell 吞 stderr**
管道执行 Python 时中文异常/traceback 可能不显示，表现为"进程静默退出"。排查加 `2>&1`。

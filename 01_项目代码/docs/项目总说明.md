## 1. 一句话架构

```
型号来源(SPEC官网)  ──► SPEC 采集 ──► SQLite ──► 型号汇总清单
                                                    │
                          ┌─────────────────────────┴──────────────────────┐
                          ▼                                                ▼
                 kakaku 价格抓取                                   kakaku 评论抓取
                （各店铺分列价格）                              （レビュー/クチコミ）
                          │                                                │
                          ▼                                                ▼
                  价格监控 CSV/XLSX                                 网评汇总 CSV/XLSX
```

- **SPEC 线**：从各品牌**官网**抓规格表，入 SQLite，按 ISO 周做快照，导出横向 Excel。
  它同时产出**型号全集清单**，是价格线和评论线的输入。
- **价格线 / 评论线**：以型号清单为输入，去 **価格.com（kakaku.com）** 抓价格与用户评价，
  产出 CSV/XLSX；加 `--save-db` 后同时入库（`product` / `price_snapshot` / `price_shop_snapshot` /
  `review` / `kakaku_task_status`），供后端 API 查询。

技术选型要点：插件式站点适配器（新增站点不改核心）、声明式抽取（选择器写 JSON）、
域名级限速 + 反爬识别、SQLite 时序快照（价格/评分只增不改）。

## 2. 代码地图

### 2.1 核心框架 `overseas/`

| 文件 | 职责 | 前后端关注点 |

```powershell
# 全量周度刷新（采集 6 品牌 → 导出 Excel → 校验 → 状态汇总）
```

## 4. 数据字典

**通用电商域**

## 5. AI / 翻译接入点（当前留空）

三列（翻译、提炼优点、提炼缺点）由 `overseas/review_export.py` 的 `AiHooks` 产生，默认 `NULL_HOOKS` 全空：

```python
from overseas.review_export import AiHooks
hooks = AiHooks(translate=fn, extract_pros=fn, extract_cons=fn)
```

抓取脚本里只有一处 `hooks = NULL_HOOKS`，接入时改这一处即可，**抓取与导出流程不变**。可选方案：

- `deep-translator`（在线免费、无需 key，量大可能限流）
- `argos-translate`（离线本地模型，不联网，日→中质量一般，可 ja→en→zh 中转）
- 自有大模型服务（翻译 + 优缺点提炼一次完成）

本版本**不引入**上述依赖，只保留接口。

## 8. 运维红线（来自实战教训）

- **不要**把业务锚点当 `wait_selector` 传给评价翻页——会被 `BlockDetector` 误判 `no_anchor_element` 拦截；真拦截靠状态码/关键字/正文过短识别。
- **HTTP 404 要优先于 blocked 判断**：404 是正常缺页（回退/跳过），不是反爬。
- **型号匹配**必须「以型号开头 > 独立词 > 子串 > 兜底」，纯子串会命中旧机型/配件。
- **解析出的相对链接必须补成绝对 URL**，否则 `goto` 静默失败。
- **导出先写 CSV 再写 XLSX**；XLSX 被 Excel 占用时自动改写带时间戳文件，绝不丢数据。
- **空/失败不得静默**：`empty`（请求成功但无数据）与 `failed`（404/超时/解析异常）必须落审计，不能用空表覆盖。
- **"抓得少" ≠ "漏抓"**：先实测核对（如新机确实 0 评价），再判断是否是 bug。
- 长任务日志会缓冲到进程结束才落盘，轮询期间读不到中间日志属正常。

```powershell
$py = 'C:\Users\likunyuan\AppData\Local\Programs\Python\Python312\python.exe'

& $py -m overseas.cli config

& $py scripts\export_spec_models.py --format all --out data\SPEC_型号汇总_$(Get-Date -Format yyyyMMdd)

& $py scripts\crawl_kakaku_reviews.py --brand hisense_jp --models 65U8S --year 2026
```

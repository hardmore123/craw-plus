# 竞品认证预警 compintel · 交接说明

## 1. 这是什么
抓各国**认证/能效注册库**，在竞品新机上市前就发现信号（新 FCC ID、新能效注册、能效等级跳变、供应商变更等）。
与电视价格/规格线解耦，自成一套表，共用主库 `data/overseas.db`。
详细业务文档见本目录 `docs/compintel_交付说明.md`（架构/CLI/6 类信号/实测）与 `docs/compintel_定时预警方案.md`（分层抓取/定时任务）。

## 2. 本文件夹内容
> 代码副本，便于单独交接。实际运行用主包 `../01_项目代码/`（同一 Python 包，自带主库和依赖）。
> 本目录的 `overseas/compintel/...` 依赖主包的 `overseas/db.py`、`fetchers.py`、`infra.py`，不能脱离主包单独运行。

| 路径 | 作用 |
|---|---|
| `overseas/compintel/orchestrator.py` | 总调度：各源抓取 → 落库 → 产生信号 |
| `overseas/compintel/compintel_db.py` | 落库与查询（建在主库 `compintel_*` 表上） |
| `overseas/compintel/fcc_crawler.py` | FCC 认证（fccid.io） |
| `overseas/compintel/eprel_crawler.py` | 欧盟 EPREL 能效注册 |
| `overseas/compintel/energystar_crawler.py` | 美国 ENERGY STAR |
| `overseas/compintel/anatel_crawler.py` | 巴西 ANATEL（ZIP-CSV） |
| `overseas/compintel/ic_ised_crawler.py` | 加拿大 IC/ISED 无线电认证 |
| `overseas/compintel/cert_crawler.py` | TÜV Rheinland + VDE/CB 安全认证 |
| `overseas/compintel/alert.py` | 信号规则（SIGNAL_TYPES） |
| `overseas/compintel/llm_analyze.py` | LLM 解读（内网接口，凭据走环境变量，见 §5） |
| `overseas/compintel/web_api.py` + `dashboard.html` | 可视化看板（端口 8088） |
| `scripts/compintel_daily.ps1` / `compintel_weekly.ps1` | 日/周定时任务脚本 |
| `scripts/compintel_install_task.ps1` | 注册 Windows 计划任务（需管理员） |
| `scripts/import_compintel_data.py` | 把 compintel 数据并入主库（已执行过） |

## 3. 数据来源网站（抓取对象）
| 源 | 覆盖 | URL | 本目录文件 |
|---|---|---|---|
| FCC | 美国无线电认证 | https://fccid.io | fcc_crawler.py |
| EPREL | 欧盟能效注册 | https://eprel.ec.europa.eu | eprel_crawler.py |
| ENERGY STAR | 美国能效 | https://www.energystar.gov（Model Index 数据集） | energystar_crawler.py |
| ANATEL | 巴西电信认证 | https://www.gov.br/anatel（ZIP-CSV） | anatel_crawler.py |
| IC/ISED | 加拿大无线电 | https://sms-sgs.ic.gc.ca/equipmentSearch | ic_ised_crawler.py |
| TÜV / VDE | 安全认证 | TÜV Rheinland Certipedia / VDE | cert_crawler.py |

搜索对象是竞品公司/品牌名（默认 Samsung / LG / Hisense / TCL / Sony / Panasonic），不是电视零售站。

## 5. 环境与凭据（部署必看）
- 抓取：FCC/EPREL/ENERGY STAR 走外网；ANATEL/ISED 可能触发验证码，脚本已限速。compintel 用独立限速器，
  **不走** `OVERSEAS_PROXY`（内网/直连）。
- LLM 解读（`compintel-analyze`）用聚好看内网接口，需在内网并设环境变量：
  `COMPINTEL_LLM_API_KEY`、`COMPINTEL_LLM_USER_KEY`（可选 `COMPINTEL_LLM_BASE_URL`，默认内网网关）。
  **原代码里明文写死的 Key 已移除改为环境变量；旧 Key 请轮换。**
- 定时任务：`scripts\compintel_install_task.ps1`（管理员）注册每日任务；管理命令见 `docs/compintel_定时预警方案.md` §4.2。

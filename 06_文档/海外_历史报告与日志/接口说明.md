# 后端 API 接口说明

供前端对接的 REST 接口。实现在 `overseas/api/`，**零第三方依赖**（Python 标准库
`http.server`），与项目「标准库优先、可离线部署」的取向一致。

- 服务层：`overseas/api/service.py`（只读查询，返回可直接 `json.dumps` 的结构）
- 任务层：`overseas/api/jobs.py`（异步触发采集，串行队列）
- 路由层：`overseas/api/server.py`（HTTP + JSON + CORS）

---

## 1. 启动

```powershell
$py = 'C:\Users\likunyuan\AppData\Local\Programs\Python\Python312\python.exe'

# 本地默认 127.0.0.1:8000
& $py -m overseas.api.server

# 指定端口 + 放开跨域（本地前端联调）
& $py -m overseas.api.server --port 8000 --cors "*"

# 指定数据库
& $py -m overseas.api.server --db data\overseas.db
```

启动参数：

| 参数 | 默认 | 说明 |
|---|---|---|
| `--host` | `127.0.0.1` | 监听地址 |
| `--port` | `8000` | 端口 |
| `--db` | `config.DB_PATH` | SQLite 路径 |
| `--cors` | 空 | `Access-Control-Allow-Origin`，联调可设 `*` |
| `--max-limit` | `5000` | 分页 `limit` 上限 |

> **安全**：服务**没有内置鉴权**，默认只监听回环地址。要对外暴露必须用
> Nginx/Caddy 反向代理，在代理层做认证与限流。systemd 单元见
> `deploy/overseas-api.service`。

---

## 2. 通用约定

- 所有响应为 JSON，`Content-Type: application/json; charset=utf-8`。
- 分页统一：`{"items": [...], "total": N, "limit": L, "offset": O}`。
- 错误统一：`{"error": "说明", "status": 4xx}`；参数非法 400，资源不存在 404，服务异常 500。
- 品牌 `code` 取值：`hisense_jp` `sony_jp` `regza_jp` `panasonic_jp` `tcl_jp` `sharp_jp`。

## 3. 查询接口

### GET `/api`

服务信息与端点清单。

### GET `/api/health`

健康检查 + 库统计。

```json
{"ok": true, "db": "...", "schema_version": 3,
 "stats": {"products": 306, "reviews": 53, "price_shop_snapshots": 1441, "spec_rows": 9188, ...}}
```

### GET `/api/brands`

六品牌概览。前端首页用。

```json
{"items": [
  {"code":"hisense_jp","name":"Hisense","brand_name":"Hisense（日本）",
   "series_count":13,"model_count":44,"latest_week":"2026-W37",
   "price_models":37,"review_models":10}
]}
```

`price_models` / `review_models` = 该品牌已成功入库价格/评论的机型数。

### GET `/api/models`

型号清单，**支持上市年份筛选**。

| 参数 | 说明 |
|---|---|
| `brand` | 品牌 code，空=全部 |
| `year` | 上市年份，如 `2026`；空=不筛选 |
| `limit` / `offset` | 分页，默认 200 / 0 |

```json
{"items":[{"brand":"hisense_jp","brand_name":"Hisense","model":"100U7S",
  "series":"U7S","release":"2026年4月下旬","release_year":2026,
  "item_id":"K0001781037","product_id":21,"size":"100\""}],
 "total":31,"limit":3,"offset":0}
```

型号取自 SPEC（权威全集），上市时间/商品ID 来自 kakaku 发售日映射。
实测 `brand=hisense_jp&year=2026` → `total=31`。

### GET `/api/spec`

SPEC 宽表（规格对比用）。

| 参数 | 说明 |
|---|---|
| `brand` | **必填**，品牌 code |
| `release` | `1`（默认）表格顶部含「上市时间」行；`0` 不含 |

```json
{"brand":"hisense_jp","brand_name":"Hisense","week":"2026-W37",
 "models":["116U9R","32S6S", ...],
 "rows":[{"category":"上市时间","item_ja":"発売日","item_zh":"上市时间",
          "values":{"116U9R":"2025年11月下旬","32S6S":""}},
         {"category":"基本仕様","item_ja":"画面サイズ","item_zh":"屏幕尺寸",
          "values":{"116U9R":"116V型"}}]}
```

海信实测：44 机型、102 行（含顶部上市时间行）。

### GET `/api/prices`

各机型最新一批店铺报价 + 整体最低价。

| 参数 | 说明 |
|---|---|
| `brand` / `model` / `year` | 过滤条件 |
| `limit` / `offset` | 分页 |

```json
{"items":[{"brand":"hisense_jp","model":"100U7S","item_id":"K0001781037",
  "product_id":21,"size":"100\"","release":"2026年4月下旬","release_year":2026,
  "status":"ok",
  "lowest":{"price":496779.0,"currency":"JPY","captured_at":"..."},
  "shops":[{"shop":"ノジマオンライン","price":501797.0,"currency":"JPY","is_lowest":false}],
  "captured_at":"..."}],
 "total":28,"limit":2,"offset":0}
```

### GET `/api/prices/history`

价格时序（画曲线用）。

| 参数 | 说明 |
|---|---|
| `product_id` | **必填** |
| `shop` | 只看某店铺，空=全部店铺 |
| `limit` | 每序列条数上限 |

```json
{"product_id":21,
 "overall":[{"price":496779.0,"currency":"JPY","captured_at":"..."}],
 "shops":[{"shop":"ケーズデンキ","price":594000.0,"is_lowest":false,"captured_at":"..."}]}
```

### GET `/api/reviews`

评论分页。

| 参数 | 说明 |
|---|---|
| `product_id` | 直接指定商品 |
| `brand` / `model` | 或按品牌/型号定位 |
| `limit` / `offset` | 分页，默认 200 / 0 |

```json
{"items":[{"product_id":55,"brand":"Hisense","model":"32A5S","size":"32\"",
  "item_id":"K0001798869","review_key":"bbs:26545226","source":"クチコミ",
  "rating":null,"title":"白はダメ","body":"スペック的にも...","author":"...",
  "review_date":"2026/09/03","review_url":"...",
  "translation":"","ai_pros":"","ai_cons":""}],
 "total":24,"limit":2,"offset":0}
```

`source` 由 `review_key` 前缀推导：`ReviewCD=` → レビュー，`bbs:` → クチコミ。
`translation` / `ai_pros` / `ai_cons` 当前恒为空字符串，接入 AI 后填充（见
`overseas/review_export.py` 的 `AiHooks`）。

### GET `/api/regions`

地区 → 站点 → 任务能力元数据（前端地区切换用）。`enabled=false` 的地区为占位（待接入适配器）。

```json
{"items":[
  {"code":"jp","name":"日本","enabled":true,
   "spec":{"task":"spec","desc":"各品牌官网规格页","sites":[
     {"site":"hisense_jp","brand":"hisense_jp","name":"Hisense","probe_url":"https://www.hisense.co.jp/tv/"}]},
   "price":{"task":"price","site":"kakaku_jp","brands":["hisense_jp","..."],"probe_url":"https://kakaku.com/kaden/lcd-tv/"},
   "review":{"task":"review","site":"kakaku_jp","brands":["..."],"probe_url":"https://kakaku.com/kaden/lcd-tv/"}},
  {"code":"ca","name":"加拿大","enabled":false,"note":"已有 amazon_ca 适配器，待接入三条线"},
  {"code":"us","name":"美国","enabled":false},
  {"code":"eu","name":"欧洲","enabled":false}
]}
```

扩展新地区：在 `overseas/api/regions.py` 的 `REGIONS` 加一项并把 `enabled` 置 true，前端无需改动。

### GET `/api/probe`

**通道验证**：抓取前探测目标站点是否可访问、是否被拦。

| 参数 | 说明 |
|---|---|
| `url` | 探测单个 URL；留空则探测 `region` 的所有目标站点 |
| `region` | 地区 code（`url` 为空时用），如 `jp` |
| `browser` | `1` 用浏览器模式（接近真实抓取，能识别 JS 软拦截，较慢）；默认 `0` 快速 HTTP |

单 URL 返回：

```json
{"url":"https://kakaku.com/kaden/lcd-tv/","ok":true,"status":200,
 "blocked":false,"block_reason":"","elapsed_ms":2670,"error":"","mode":"http"}
```

整地区返回 `{"items":[{region,cap,site,name,url, ...同上}]}`。

`ok=true` 可访问；`blocked=true` 被反爬拦截（`block_reason`）；`error` 非空为不可达。
实测：日本六品牌官网中 SHARP 的快速 HTTP 探测不可达（`status=0`），需 `browser=1` 或抓取时用浏览器——这正是通道验证的用途：先探再抓。

### GET `/api/status`

采集状态（前端「哪些没抓到、为什么」）。

| 参数 | 说明 |
|---|---|
| `task` | `price` / `review` / `release`；空=同时含 SPEC 系列状态 |
| `brand` | 品牌 code |
| `state` | 状态值，如 `ok` `no_item` `no_reviews` `blocked` `failed` |
| `week` | SPEC 周，如 `2026-W37` |

```json
{"counts":{"price":{"ok":46},"review":{"ok":14}},
 "items":[{"kind":"kakaku","task":"price","brand":"hisense_jp","model":"24A4S",
           "item_id":"K0001789011","status":"ok","release":"2026年6月中旬",
           "release_year":2026,"row_count":6,"new_count":0,"message":"...",
           "captured_at":"..."}],
 "total":46,"limit":2,"offset":0}
```

状态含义：`ok` 成功；`no_item` 站内无此商品页；`not_target_year` 非目标上市年份；
`no_reviews` 无评价；`no_price` 无价格；`blocked` 被反爬拦截；`failed` HTTP/解析异常。

## 4. 任务接口（触发采集）

采集是长任务（SPEC 全量数十分钟、kakaku 单品牌 15–25 分钟），因此**异步执行**：
提交返回 `job_id`，前端轮询状态与日志。

任务**串行**执行（单工作线程 + FIFO 队列）：抓取必须限速，且 SQLite 写并发弱，
并行只会更容易被封和锁库。

### POST `/api/jobs`

```json
{"task": "price", "params": {"brands": ["hisense_jp"], "year": 2026}}
```

返回 `202` + 任务对象（`status` 初始为 `queued`）。

支持的 `task` 与 `params`：

| task | params | 对应命令 |
|---|---|---|
| `spec` | `brand`（必填）、`series[]` | `cli spec-crawl` |
| `spec_refresh` | `brands[]`、`export_only`、`region` | `scripts/refresh_spec.py` |
| `price` | `brands[]`、`year`、`limit_models`、`region` | `crawl_kakaku_prices.py --save-db`（jp）/ `crawl_ca_retail.py`（非 jp） |
| `review` | `brand`、`year`、`models[]`、`limit_models`、`translate`、`extract_pros`、`extract_cons`、`translate_engine`、`region` | `crawl_kakaku_reviews.py --save-db`（jp）/ `crawl_ca_retail.py`（非 jp） |
| `ca_retail` | `brands[]`、`sites[]`、`models[]`、`limit_models`、`max_reviews`、`region` | `crawl_ca_retail.py` |
| `release` | `brand` | `crawl_kakaku_release.py` |

> **多地区（region）**：所有任务可带 `region`（缺省 `jp`）。前端切换「地区」下拉后，
> 任务会自动带上当前地区。日本线（`jp`）行为不变；加拿大线（`ca`）价格与网评来自
> **同一商品页同步抓取**，所以 `price` 和 `review` 都会路由到 `crawl_ca_retail.py`
> （一条命令同时产出价格与网评两张表），也可直接用 `ca_retail` 任务。
>
> 加拿大线示例：
>
> ```json
> {"task":"spec_refresh","params":{"region":"ca","brands":["hisense_ca"]}}
> {"task":"ca_retail","params":{"region":"ca","brands":["hisense_ca"],
>  "sites":["amazon_ca"],"limit_models":5,"max_reviews":10}}
> ```
>
> 加拿大 6 品牌：`hisense_ca` / `samsung_ca` / `tcl_ca` / `lg_ca` / `sony_ca` / `philips_ca`；
> 8 零售站：`amazon_ca` / `bestbuy_ca` / `walmart_ca` / `costco_ca` / `thebrick_ca` /
> `leons_ca` / `visions_ca` / `canadiantire_ca`（默认仅 `amazon_ca` 启用，其余待联网验证后开）。

> 网评任务的三个 AI 字段是独立选项：`translate=true` 只翻译，`extract_pros=true`
> 只提炼优点，`extract_cons=true` 只提炼缺点；任意组合均可。`translate_engine`
> 可选 `nllb`、`argos`、`xinghai`，其中优缺点提炼需要已配置的 xinghai-ultra。
>
> 例如同时启用翻译和优缺点提炼：
>
> ```json
> {"task":"review","params":{"brand":"hisense_jp","year":2026,
>  "translate":true,"extract_pros":true,"extract_cons":true,
>  "translate_engine":"xinghai"}}
> ```

> 只接受白名单任务，参数由后端显式拼装成命令行，**不接受前端传任意命令**。

### GET `/api/jobs`

任务列表 + 队列信息。

```json
{"queue":{"running":null,"queued":[],"total_jobs":3},
 "items":[{"id":"13d04c97e459","task":"review","params":{...},
           "status":"succeeded","created_at":"...","started_at":"...",
           "finished_at":"...","exit_code":0,"message":"完成"}]}
```

### GET `/api/jobs/<id>`

单任务状态。`status` 流转：`queued` → `running` → `succeeded` / `failed` / `cancelled`。

### GET `/api/jobs/<id>/log?offset=0`

增量拉日志（轮询用）：返回从 `offset` 起的内容与新 `offset`。

```json
{"id":"13d04c97e459","offset":1024,"size":2048,"content":"...","eof":false}
```

前端做法：首次 `offset=0`，之后用上次返回的 `offset` 继续拉，`eof=true` 且任务终态时停止。

### POST `/api/jobs/<id>/cancel`

取消任务。排队中直接移除；运行中终止子进程。返回 `{"id":"...","cancelled":true}`，
无法取消时返回 `409`。

## 3b. 导出下载

把库里的数据导出为 Excel/CSV 文件流，浏览器直接下载（附件形式，不落服务器磁盘）。
列格式与手动导出、抓取脚本产出的文件完全一致。

### GET `/api/export/spec?brand=&format=xlsx`

导出某品牌 SPEC 宽表（含顶部上市时间行）。`brand` **必填**。

### GET `/api/export/reviews?brand=&format=xlsx&translate=1&engine=xinghai`

导出评价（通用 20 列模板）。`brand` 可空=全部品牌。默认不现场翻译；传
`translate=1` 后才调用翻译后端。`engine` 可选 `nllb`（默认）、`argos` 或
`xinghai`；xinghai 从环境变量读取凭据，请求失败时回退到离线引擎。整库翻译耗时较长，
生产环境建议使用 `scripts/backfill_review_translations.py` 生成文件后再下载。

### GET `/api/export/prices?brand=&format=xlsx`

导出价格（8 店铺分列模板）。`brand` 可空=全部品牌。

公共参数 `format`：`xlsx`（默认）或 `csv`。响应带 `Content-Disposition: attachment`，
文件名如 `SPEC_海信_20260909.xlsx`、`价格监控_全部品牌_20260909.csv`（中文名用 RFC5987 编码，不乱码）。

前端在「抓取 SPEC / 抓取评价 / 抓取价格」三页的预览工具栏各有「导出 Excel / CSV」按钮，
按当前所选品牌下载。

## 4b. 定时任务接口

周期性自动抓取。规则持久化到 `data/schedules.json`，后台线程每 30 秒检查，到点入队（仍串行执行）。

### GET `/api/schedules`

```json
{"items":[{"id":"b1cbb17fc933","name":"海信价格周更","task":"price",
  "params":{"brands":["hisense_jp"],"year":2026},
  "trigger":{"kind":"weekly","weekday":6,"hour":3,"minute":20},
  "enabled":true,"next_run_at":"2026-09-13T03:20","last_run_at":"","last_job_id":""}]}
```

### POST `/api/schedules`

```json
{"task":"price","params":{"brands":["hisense_jp"],"year":2026},
 "trigger":{"kind":"weekly","weekday":6,"hour":3,"minute":20},
 "name":"海信价格周更"}
```

触发规则 `trigger` 两种：

| kind | 字段 | 说明 |
|---|---|---|
| `weekly` | `weekday`(0=周一..6=周日)、`hour`、`minute` | 每周某天某时 |
| `interval` | `every_hours` | 每 N 小时 |

返回 `201` + 定时对象（含算好的 `next_run_at`）。`task`/`params` 同 `POST /api/jobs`。

### POST `/api/schedules/<id>`

更新：传 `{"enabled":false}` 启停，或传 `trigger`/`params`/`name` 改配置。

### POST `/api/schedules/<id>/delete`

删除。返回 `{"id":"...","deleted":true}`。

## 5. 前端页面

内置单页前端（**海信蓝**主题）由本服务的静态目录 `overseas/api/static/` 提供，
访问根路径 `http://<host>:<port>/` 即打开。零构建、零依赖（原生 HTML/CSS/JS）。

六个标签页：

| 标签 | 功能 | 主要接口 |
|---|---|---|
| 抓取 SPEC | 选品牌/系列 → 抓取 → 看日志 → 预览规格宽表 → **导出** | `POST /api/jobs`(spec/spec_refresh)、`/api/spec`、`/api/export/spec` |
| 抓取评价 | 选品牌/年份/型号 → 抓取 → 预览评价 → **导出** | `POST /api/jobs`(review)、`/api/reviews`、`/api/export/reviews` |
| 抓取价格 | 选品牌/年份 → 抓取 → 预览价格（点行看各店铺）→ **导出** | `POST /api/jobs`(price)、`/api/prices`、`/api/export/prices` |
| 通道验证 | 单 URL 或整地区探测可访问性 | `/api/probe` |
| 定时任务 | 新建/启停/删除周期任务 | `/api/schedules` |
| 运行记录 | 任务列表 + 队列 + 点任务看实时日志 | `/api/jobs`、`/api/jobs/<id>/log` |

顶栏可切换地区（当前日本可用，加拿大/美国/欧洲为占位，接入适配器后自动可用）。

### 5.1 对接要点

典型页面与接口对应：

| 页面 | 接口 |
|---|---|
| 首页概览 | `/api/brands`、`/api/health` |
| 型号列表（按上市时间筛选） | `/api/models?brand=&year=` |
| 规格对比 | `/api/spec?brand=` |
| 价格监控 | `/api/prices?brand=&year=`，点开用 `/api/prices/history?product_id=` |
| 评论浏览 | `/api/reviews?brand=&model=&limit=&offset=` |
| 采集运维 | `/api/status`、`/api/jobs`（提交 + 轮询日志） |

注意：

- `/api/spec` 返回整张宽表（海信 44 机型 × 102 行），数据量较大，前端建议做虚拟滚动或按需列显示；
- 长任务不要用同步请求等待，一律走 `POST /api/jobs` + 轮询；
- 采集期间数据库有写入，读接口仍可正常响应（已开 WAL）。

## 6. 部署

```bash
sudo cp deploy/overseas-api.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now overseas-api
systemctl status overseas-api
curl -s http://127.0.0.1:8000/api/health
```

启动后前端与 API 同端口：前端在 `/`，接口在 `/api/*`。反向代理示例（Nginx，代理层加认证，前端与 API 一起代理）：

```nginx
location / {
    auth_basic "overseas";
    auth_basic_user_file /etc/nginx/.htpasswd;
    proxy_pass http://127.0.0.1:8000;
    proxy_read_timeout 120s;   # 通道验证浏览器模式较慢，超时给足
}
```

说明：

- 前端是静态单页，由 API 服务的 `overseas/api/static/` 直接提供，**无需单独构建或部署 Node**；
- 定时任务由 API 进程内的调度线程执行（`data/schedules.json` 持久化）。若 API 服务重启，已配置的定时任务会自动加载并重算下次运行时间；
- 定时任务与 systemd 的 `overseas-spec.timer`（周度 SPEC）可并存：前者面向"前端配置的按需周期任务"，后者是"运维固定的周度全量刷新"。

其它部署细节（离线 Chrome、环境变量、系统定时任务）见 `部署说明.md` 与 `项目总说明.md` §7。

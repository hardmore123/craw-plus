### 表 23：fact_benchmark_comparison（竞品对阵对比表）

**构建方法**：基于product + price_snapshot + spec_row数据，按尺寸×价格带自动匹配对阵组合。

#### 对阵匹配规则

1. **尺寸分组**：从product.size提取英寸数，按55/65/75/85/98/100分组
2. **价格带划分**：按均价划分
   - 入门：< $500 (55寸) / < $800 (65寸)
   - 中端：$500-$1000 (55寸) / $800-$1500 (65寸)
   - 高端：$1000-$2000 (55寸) / $1500-$3000 (65寸)
   - 旗舰：> $2000 (55寸) / > $3000 (65寸)
3. **对阵组合**：每价格带选海信型号 + 竞品同档型号（Samsung/LG/Sony/TCL各1）

#### 示例对阵（从现有数据可构建）

| comparison_name | size_inch | price_band | our_model | competitor_models |
|----------------|-----------|-----------|-----------|------------------|
| 55寸旗舰对阵 | 55 | 旗舰 | Hisense 55U8N | Samsung 55QN90F, LG 55G5, Sony 55A95L |
| 65寸高端对阵 | 65 | 高端 | Hisense 65U7N | Samsung 65Q80D, LG 65C4, Sony 65X90L |
| 75寸中端对阵 | 75 | 中端 | Hisense 75U6 | Samsung 75DU7200, LG 75UT80, TCL 75C6 |
| 85寸旗舰对阵 | 85 | 旗舰 | Hisense 85U8N | Samsung 85QN900D, LG 85G4, Sony 85X93L |

**构建SQL**：

## 构建步骤

### Step 1: 建表DDL
```sql
-- dim_spec_parameter
CREATE TABLE dim_spec_parameter (
    param_id INT PRIMARY KEY,
    param_code VARCHAR(30) UNIQUE NOT NULL,
    param_name VARCHAR(50) NOT NULL,
    param_unit VARCHAR(20),
    is_numeric TINYINT NOT NULL DEFAULT 1,
    higher_is_better TINYINT,
    category VARCHAR(20) NOT NULL,
    sort_order INT NOT NULL DEFAULT 0
);
CREATE INDEX idx_dim_spec_parameter_category ON dim_spec_parameter(category);

-- dim_spec_normalization_map
CREATE TABLE dim_spec_normalization_map (
    map_id INT PRIMARY KEY,
    hisense_term VARCHAR(100) NOT NULL,
    competitor_terms TEXT NOT NULL,
    param_id INT,
    normalized_category VARCHAR(50) NOT NULL,
    status VARCHAR(20) NOT NULL DEFAULT 'PENDING',
    confirmed_by INT,
    confirmed_at DATETIME,
    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    note VARCHAR(200),
    FOREIGN KEY (param_id) REFERENCES dim_spec_parameter(param_id)
);
CREATE INDEX idx_norm_map_hisense ON dim_spec_normalization_map(hisense_term);
CREATE INDEX idx_norm_map_param ON dim_spec_normalization_map(param_id);
CREATE INDEX idx_norm_map_status ON dim_spec_normalization_map(status);

-- fact_benchmark_comparison
CREATE TABLE fact_benchmark_comparison (
    comparison_id INT PRIMARY KEY,
    comparison_name VARCHAR(100) NOT NULL,
    size_inch INT NOT NULL,
    price_band VARCHAR(30) NOT NULL,
    our_model_id INT NOT NULL,
    competitor_model_ids TEXT NOT NULL,
    advantage_points TEXT,
    disadvantage_points TEXT,
    opportunity_points TEXT,
    advantage_confidence DECIMAL(5,2),
    disadvantage_confidence DECIMAL(5,2),
    opportunity_confidence DECIMAL(5,2),
    strategy_suggestion TEXT,
    created_by INT,
    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    snapshot_date DATE NOT NULL
);
CREATE INDEX idx_benchmark_size ON fact_benchmark_comparison(size_inch);
CREATE INDEX idx_benchmark_band ON fact_benchmark_comparison(price_band);
CREATE INDEX idx_benchmark_our ON fact_benchmark_comparison(our_model_id);
CREATE INDEX idx_benchmark_created ON fact_benchmark_comparison(created_at);
```

## 数据映射问题与注意事项

### 1. category归一化需人工补充
源数据280+种category中，约40种为乱码/系列名（pim-grp-xxx/ZX3 series），无法自动映射，需人工识别或标记为"其他"。

### 2. item_ja缺失
部分spec_row的item_ja为空（Hisense等品牌），需用item_zh或category兜底。

### 3. 值格式不统一
- 亮度：`"1500nits"` / `"1,500"` / `"Peak Brightness(nits): 1500"` → 需正则提取数值
- 刷新率：`"144Hz"` / `"120Hz(VRR)"` / `"60 Hz"` → 需提取Hz数值
- HDMI：`"4"` / `"4K 144Hz"` / `"HDMI 2.1"` → 需判断是否2.1

### 4. dim_product_model表缺失
fact_benchmark_comparison需要our_model_id/competitor_model_ids关联产品型号表，需额外构建dim_product_model（从product表提取去重型号+品牌+尺寸）。

### 5. AI对阵结论需AI生成
advantage_points/disadvantage_points/opportunity_points需基于规格对比由AI生成，非纯SQL可构建。可先用空值占位，后续AI填充。

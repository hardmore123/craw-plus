## 一、项目 1：CertAgent

### 1.1 service 定义（`deploy/certagent.service`）

```ini
[Unit]
Description=CertAgent Backend (FastAPI + Uvicorn)
After=network.target

[Service]
Type=simple
User=hisense
Group=hisense
WorkingDirectory=/home/hisense/pro/Gitlab/CertAgent
Environment="HOME=/home/hisense"
Environment="PATH=/home/hisense/pro/Gitlab/CertAgent/venv/bin:/usr/local/bin:/usr/bin"
ExecStart=/home/hisense/pro/Gitlab/CertAgent/venv/bin/uvicorn webapi.app:app --host 127.0.0.1 --port 8125 --workers 1
Restart=always
RestartSec=5
StandardOutput=journal
StandardError=journal

[Install]
WantedBy=multi-user.target
```

> 注：路径依据 `C:\Users\likunyuan\Desktop\项目\CertAgent\Linux\deploy\certagent.service` 原文为 `hisense`，与本仓库一致，不再额外标注。

### 1.2 Nginx 站点（8123，`deploy/nginx.conf`）

```nginx
server {
    listen 8123;
    server_name 10.18.87.51;
    root /home/hisense/pro/Gitlab/CertAgent/frontend/dist;
    client_max_body_size 50m;
    location /api/  { proxy_pass http://127.0.0.1:8125; proxy_read_timeout 300s; proxy_send_timeout 300s; }
    location /health { proxy_pass http://127.0.0.1:8125; }

```

### 1.3 依赖关系

```
同事浏览器 → nginx:8123 ──/api 反代──> certagent.service:8125
                          (前端静态在 frontend/dist)
```
- nginx 挂了 → 前端 502（后端正常）
- certagent 挂了 → 前端在但接口失败 → `Restart=always` 自动拉起



### 2.2 断电重启保护（2026-09-24 已实施）

改动集中在 `crawl4ai-main/Linux/deploy/`：

| 机制 | 配置 | 作用 |
|---|---|---|
| 启动前依赖探测 | `ExecStartPre` → `cert_verify_ready.sh`（新增） | 依次等路由(≤60s) → 解密8500(≤60s) → `CERT_PROXY`(≤60s)；任一超时只告警、**永远 `exit 0`** |
| 崩溃自动恢复 | `Restart=on-failure` + `RestartSec=5` | 主进程崩溃后 5s 重试 |
| 无限次启动尝试 | `StartLimitIntervalSec=0` | 关闭默认「10s 内失败 5 次即永久 failed」|
| 弱依赖 | `After=`/`Wants=decryptor.service` | 解密服务缺失不连锁 failed |
| 探测时间放宽 | `TimeoutStartSec=240` | 默认 90s 会误杀 |

`cert_verify_ready.sh` 内容（关键：三类探测各限时、超时降级、始终 exit 0）。

```bash
# 1. 等路由(≤60s) 2. 等解密8500(≤60s) 3. 等CERT_PROXY(≤60s) 4. 缓冲2s
# 全部超时/缺失仅写 /tmp/cert_verify_ready.log，不返回非零
exit 0
```

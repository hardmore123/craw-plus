# 电视产品运营 AI 智能分析与决策支持平台：UI 交互界面设计

**核心判断：**本平台不是"一个大而全的看板"，而是"三角色视角 × 七大业务模块 × 界面模式库"的体系。本版已按三角色日常任务模型深化至可直接开发与使用的详细设计（含页面级区块、组件、交互、状态与任务流）。

- **路径：**严格按"数据 → 洞察 → 产品改进与规划"落地，以网页爬取全表为数据底座，AI 能力规划第 3 章的分析层与决策支持层能力全部映射为可操作界面。

- **入口分层：**产品线总经理用"一屏决策总览"、产品经理用"分析工作台"、汇总运营总界面用"对标与组合"，三者同一数据底座，下钻路径连通。

- **组件复用：**21 种界面模式沉淀为标准组件（KPI 卡、AI 洞察卡、预警卡、趋势折线、SPEC 对比矩阵、雷达、审批队列、证据抽屉等），各模块共用，避免重复建设。

- **落地节奏：**先做"数据接入 \+ 运营总览 \+ 竞品对阵 \+ 价格监控 \+ 预警中心"的 MVP，再补网评、新品预警、促销预测，最后完成决策工作台与汇总对标。

本文档面向产品运营专家、UI 设计与研发团队，作为"电视产品运营 AI 智能分析与决策支持平台"界面建设的评审与开发依据。设计输入为三份已评审材料：网页数据爬取需求整理（全表数据域与刷新规则）、基于产品运营基础数据的 AI 能力规划（第 3 章 AI 能力清单）、产品运营 UI 界面基本设计要素（角色定位、运营域拆解与界面模式）。本方案在既有 AI 能力清单之上，逐一展开"每个能力在界面上怎么呈现、怎么交互、支撑哪些决策"。本次深化版：①七大业务模块页面升级为区块级详细设计（目标/结构/交互/状态/AI 映射/任务流）；②三角色页面从定位描述深化为专属页面清单与日常任务流；③新增汇总运营总界面四页设计与全局体验要素章节；④线框由三组扩展至五组覆盖 11 个页面。

# 设计总则

## 设计目标：三类角色的任务

平台服务于三类角色，界面深度按任务差异化，但共享同一数据底座与指标口径。下表为角色定位总览，页面定位详见第四章。

|角色|核心任务|界面定位|高频动作|
|---|---|---|---|
|**产品线总经理**|一屏看清本产品线竞争态势，快速拍板|运营总览 \+ 预警中心 \+ 竞争决策（结论优先）|看结论、处置预警、指派任务、订阅周报|
|**产品经理**|弄清变化原因，形成产品改进与应对建议|分析工作台（全模块下钻、标注、导出）|对阵研判、痛点分析、生成建议、发起决策|
|**汇总运营总界面**|跨产品线横向对标，做组合与资源分配|对标与组合视图（跨线比较、全球视角）|跨线对标、全球价格、预警汇总、下钻单线|

## 设计原则

- **数据驱动、结论先行：**所有界面默认展示 AI 结论与证据，不要求用户从原始数据自行推导；每个结论可一键溯源到明细证据（价格记录、评价原文、认证记录等）。

- **一图一问题：**每个图表只回答一个运营问题，图表看模式、表格查明细、文字补条件，不重复呈现同一信息。

- **异常优先：**预警中心是贯穿性支撑模块，跨模块聚合、按严重度分级，是总经理界面的第一优先信息，保证"可见—可查—可指派"。

- **入口分层、数据同源：**三角色入口不同但共用一套指标与明细，避免各建一套数据；汇总界面下钻即可回到单线总览与工作台。

- **组件化复用：**漏斗、趋势、排行、对比矩阵、告警等跨模块界面抽成标准组件库，七大模块与三角色界面共同调用。

## 全链路：数据 → 洞察 → 产品改进与规划

平台按四层映射组织界面：数据层（全表）承载爬取底座，智能分析层输出洞察，产品决策支持层输出建议，UI 呈现层按角色与模块组织视图。AI 能力规划第 3 章的结构化—智能分析—决策支持三层，在此完整映射到界面。

三层能力与界面承载关系：**数据结构化层**对应"数据健康台"界面（爬虫任务状态、数据新鲜度、SPEC 归一化表维护），是全平台的底座；**智能分析层**的 12 项能力对应各业务模块的洞察视图（对比、预测、聚类、异常、情感）；**产品决策支持层**的 5 项能力对应"产品竞争决策工作台"。用户从任何模块进入，都沿"看洞察 → 追证据 → 做决策"的路径闭环。

# 总体信息架构

## 全局框架与全局筛选器

平台采用"顶部筛选器 \+ 左侧导航 \+ 主内容区"的框架。全局筛选器是整套 UI 的骨架，一处设置、全局联动，贯穿所有模块与角色界面。

|筛选维度|取值（示例）|说明|
|---|---|---|
|**区域**|AM / EU / AP / JP / 全球|对应全表四个区域；汇总总界面默认"全球"，单线界面默认本线区域。|
|**产品线**|全部 / 旗舰 / 中端 / 入门 / 画框 / 商用（示例）|产品线清单与数据权限绑定，落地前需确认最终划分。|
|**时间粒度**|周 / 月 / 季度 / 自定义|与爬取刷新频次对齐：SPEC 双周/周度、价格周度、网评周度。|
|**品牌**|海信 / TCL / Samsung / LG / Sony / Philips|竞品品牌随各区域主销竞品配置。|
|**渠道**|Amazon / BestBuy / Walmart / MediaMarkt / kakaku 等|渠道清单按各区域爬取模板维护。|

筛选结果在导航与内容区同步回显；支持"保存常用视图"，下次进入一键恢复。

## 三层导航与模块地图

导航采用三层结构：总览层（一屏结论）→ 模块工作区（七大业务模块 \+ 决策工作台）→ 明细层（证据可追溯），层间单向递进、可回退。预警中心与数据健康台为贯穿性入口，不归属单一业务域。

七大业务模块对应 AI 能力规划的业务覆盖：竞品对阵分析、价格策略监控、竞品新品上市提前预警、用户网评监测、行业技术趋势、竞品促销活动预测、产品竞争决策；运营总览承接全部模块结论，作为总经理默认首页。

## 角色 × 模块使用矩阵

同一套数据与指标，按角色任务差异化配置视图深度与权限：总经理看结论、产品经理做分析、汇总界面做对标。

# 七大业务模块界面设计

以下逐模块展开"运营问题 → 页面结构 → AI 能力呈现 → 关键交互 → 核心指标"，每个模块均遵循"数据—洞察—产品改进与规划"路径：先展示 AI 洞察与证据，再提供下钻与决策动作。

## 运营总览：总经理的一屏决策入口

**页面目标：**本产品线整体竞争态势一屏看清，回答三个问题：今天必须处理什么？要不要做决策？决策到哪一步了？本页只展示结论与异常，分析动作统一引导到工作台。

**页面结构（自上而下五区）：**KPI 红绿灯卡墙 → AI 洞察列表（五要素卡片）→ 预警聚合条 → 竞品动态时间线 → 决策入口区。

|区块|关键组件|内容与数据|交互与下钻|
|---|---|---|---|
|**KPI 卡墙**|KPI 卡 ×5|产品竞争力指数、价格竞争力（均价差）、网评健康度、待处置预警数、市场机会点数；每卡含目标—实际差距条，异常标红并附 24h 变化。|点击卡进入对应模块并带入筛选；hover 显示口径说明（数据源/周期）。|
|**AI 洞察列表**|AI 洞察卡（五要素）|聚合当日/本周高价值洞察，按严重度排序，最多 7 条；每条为现象\+证据\+建议\+置信度\+溯源。|点击直达对应模块；展开证据；误报标记；一键加入周报草稿。|
|**预警聚合条**|预警计数徽标|高/中/低三级预警计数与较昨日变化。|点击进入预警中心；高优先级预警顶栏同步提示。|
|**竞品动态时间线**|时间轴组件|本周竞品新品上架、降价、促销、认证事件按时间排列，每条标注影响判断与相关型号。|点击事件查看证据与归因；事件可勾选加入周报。|
|**决策入口区**|待办卡 \+ 简报按钮|待我审批的决策数、进行中决策进度；一键生成/订阅日报周报。|点击进入决策审批队列；订阅管理弹窗。|

- **关键交互：**时间粒度切换（周/月）联动本页全部区块；洞察卡支持"已读"与"不再推荐同类"反馈，误报进入效果评估样本；订阅日报/周报在此设置。

- **状态与空态：**无数据时显示空态引导（配置入口\+说明），数据源异常时对应 KPI 卡降级标注"数据待更新"并提示最近成功刷新时间。

- **AI 能力映射：**产品竞争力自动评价（结论卡）、异常检测（标红）、洞察生成（日/周自动聚合）、竞品新品动态自动识别（时间线）。

- **数据依赖：**全表 SPEC/价格/网评/认证四个数据域，刷新频次与全局筛选器对齐；指标口径在模块标题旁就近展示。

**跳转链：**洞察卡 → 对应模块工作区；预警条 → 预警中心；待办卡 → 决策审批队列；竞品事件 → 竞品对阵/价格监控。所有下钻自动继承本页筛选条件。

## 竞品对阵分析

**页面目标：**回答"我方与竞品在参数、卖点、价格上谁强谁弱、机会在哪里"，支持从单型号对阵到多型号横向对比，结论可直接引用。

**页面结构（自上而下）：**对阵对象选择条 → SPEC 归一化对比表 → 能力雷达图 → 营销卖点提取 → AI 对阵结论卡。

|区块|关键组件|内容与数据|交互与下钻|
|---|---|---|---|
|**对阵对象选择**|型号选择器|选择我方型号与 1—4 个竞品型号；AI 按价格带与定位推荐对阵组合（如 55 吋旗舰档：海信 U9N vs TCL X11K vs Samsung QN90F vs LG G5）。|推荐组合一键采纳；自定义选择后保存常用对阵。|
|**SPEC 归一化对比表**|SPEC 对比矩阵|基于归一化映射表对齐术语（QD/QLED/Quantum Dot），逐参数对比并用颜色标注优劣势，自动输出判定逻辑（如峰值亮度 1300nits 高于 1000nits → 亮度领先）。|参数点击跳转明细溯源；归一化缺失术语标注"待维护"并提示候选映射。|
|**能力雷达图**|能力雷达|画质、音质、智能、游戏、设计、连接六维能力对比，快速定位短板。|点击维度查看该维度的参数构成与判定依据。|
|**营销卖点提取**|卖点标签流|AI 抓取竞品详情页/官网宣传文案，提取主打卖点概念（多模态识别），标注置信度。|卖点点击查看原文出处；低置信度卖点标记待人工确认。|
|**AI 对阵结论卡**|三栏结论卡|自动生成"优势点 / 劣势点 / 机会点"三栏结论，每条可溯源到具体参数、价格或网评证据。|结论卡一键生成可导出对阵报告；机会点一键转入决策工作台。|

- **关键交互：**切换对阵型号实时重算；参数点击跳转明细溯源；一键生成可导出的对阵报告；常用对阵组合保存复用。

- **状态与空态：**未选择对阵对象时显示引导页；归一化映射缺失时标注"待维护"并给出候选映射；竞品 SPEC 缺失时以"—"展示并提示数据源缺口。

- **AI 能力映射：**SPEC 对比自动分析与优劣势判定、竞品新品自动识别（价格/SPEC/卖点）、产品竞争力自动评价。

- **数据依赖：**全表 SPEC 域（双周刷新）\+ 营销卖点抽取任务；SPEC 归一化映射表需持续维护，新品类新技术出现时及时更新（技术点 1）。

- **跳转链：**结论卡 → 溯源证据（参数/价格/评价原文）；新品情报 → 新品预警详情；机会点 → 产品竞争决策工作台。核心指标：领先参数数、落后参数数、机会点数。

**面向产品经理的任务流：**收到竞品新品/降价信号 → 建立对阵 → 看优劣势与机会点 → 生成对阵报告/发起机会点决策，全程留痕可回溯。

## 价格策略监控

**页面目标：**回答"价格有没有竞争力、竞品在怎么降价、哪个渠道定价异常、未来怎么走"，支撑跟价、错位、渠道治理等定价决策。

**页面结构（自上而下）：**价格趋势折线 → 多渠道价格比对表 → 定价策略分析 → AI 价格预测 → 全球价格监测。

|区块|关键组件|内容与数据|交互与下钻|
|---|---|---|---|
|**价格趋势折线**|趋势折线（事件标注）|我方与竞品分渠道/分区域均价走势（周度数据），关键拐点标注事件（大促、新品上市、降价启动）。|渠道/品牌切换；拐点点击查看事件与影响面。|
|**多渠道价格比对表**|价格比对表 \+ 异常标注|同一型号跨渠道最高/最低价与价差，AI 自动标注异常定价（同型号某渠道显著低于其他渠道）与渠道倒挂。|异常点击查看归因与影响面；一键加入跟进清单。|
|**定价策略分析**|策略摘要卡|识别竞品降价节奏、促销周期与让利力度，输出竞品定价策略摘要（主动降价/跟随型/清库存型）。|策略类型点击查看判定依据；支持导出。|
|**AI 价格预测**|预测视图（置信区间）|基于历史价格与促销周期，预测未来 4—8 周价格走势，给出置信区间与关键事件假设。|预测参数调整后重算；查看假设列表；订阅价格预警。|
|**全球价格监测**|全球价格矩阵|同型号跨区域价格对比（可切换本币/汇率视角），支撑全球定价一致性判断。|单元格点击查看渠道明细；异常标红。|

- **关键交互：**渠道/品牌/时间切换实时重算；预测参数调整后重算；异常价格点击查看归因与影响面；订阅价格日报。

- **状态与空态：**渠道无价格数据时显示空缺原因（爬取失败/未上架）；预测数据不足时标注置信度下调原因；异常价格支持标记"已知，跟踪中"。

- **AI 能力映射：**竞品价格趋势自动分析与预测、多渠道价格智能比对、促销活动自动识别、产品定价异常监测。

- **数据依赖：**全表价格域（周度刷新）\+ 促销活动记录；汇率数据接入全球视角；核心指标：均价差、价差幅度、异常定价数、预测置信度。

- **跳转链：**价格异常 → 预警详情；预测结果 → 促销预测/应对建议；全球矩阵 → 汇总运营总界面。

**面向产品经理的任务流：**价格预警 → 查看趋势与渠道分布 → 判定策略类型（清库存/新老品切换）→ 生成跟价/错位建议 → 发起定价决策审批。

## 竞品新品上市提前预警

**页面目标：**在竞品新品正式上市前提前发现并评估冲击，回答"下一款竞品什么时候来、什么配置、会不会冲击我方、要不要提前应对"。

**数据源（多源交叉验证，命中来源越多置信度越高）：**FCC 认证库（FCC ID、发证时间）、ENERGY STAR 清单、NRCan、EPREL 能效注册（含欧洲上市时间）、竞品官网与主销渠道上架、评测机构预告。

|区块|关键组件|内容与数据|交互与下钻|
|---|---|---|---|
|**预警卡片列表**|预警卡片（分级）|按预警等级排序；卡片含品牌、型号、预警来源、认证/注册时间、预计上市时间、关键参数初判、建议动作。|卡片点击进入详情；支持按品牌/区域/来源筛选；一键指派研判。|
|**上市窗口时间轴**|时间轴组件|从认证时间推算到预计上市的窗口期；多来源交叉验证（如 FCC \+ EPREL 双源命中提升置信度）。|窗口节点点击查看推算依据；双源/单源标识。|
|**新品情报详情**|情报详情卡|规格预览、卖点初判、与我方对阵产品的初步建议。|一键转入竞品对阵分析；加入关注清单。|
|**冲击评估区**|威胁评估卡|AI 评估新品对我方在售/规划产品的威胁等级（高/中/低）与影响面（价格带、区域、卖点重叠度）。|威胁等级点击查看评估依据；生成应对建议草稿。|

**预警规则配置（产品经理可维护）：**关注品牌、区域、认证库、提前天数、威胁等级阈值；命中后自动推送并生成预警卡。

- **关键交互：**预警规则配置（品牌、区域、认证库、提前天数）；命中后自动推送；责任人指派与跟踪；威胁评估后一键发起应对决策。

- **状态与空态：**无新认证时显示"近期无新品信号"；单源命中标注置信度低并提示补源；误报可标记并反馈至模型优化。

- **AI 能力映射：**竞品新品提前预警（FCC 等认证识别）、竞品新品自动识别（价格/SPEC/营销卖点提取）、市场机会/威胁自动识别。

**核心指标与跳转：**预警平均提前量（周）、预警命中率、双源验证覆盖率；跳转：新品详情 → 竞品对阵 → 决策工作台。任务流：检出认证 → 评估威胁 → 生成应对建议 → 指派研判。

## 用户网评监测

**页面目标：**回答"用户怎么评价我方与竞品、差在哪里、需要什么、热度怎么变"，把网评声量转化为产品改进输入。

**页面结构（自上而下）：**网评总览 → 痛点聚类排行 → 高频需求热度榜 → 热度变化曲线 → 单条评价下钻。

|区块|关键组件|内容与数据|交互与下钻|
|---|---|---|---|
|**网评总览**|KPI 卡墙|平均评分、评价声量、负面占比、情感分布（正/中/负），与上周期对比。|点击指标进入对应分析视图；对比基准可切换（我方/竞品/行业）。|
|**痛点聚类排行**|聚类排行（增速标记）|AI 将负面评价自动聚类（开机广告、运动画面模糊、游戏延迟、接口兼容等），展示各聚类声量占比与趋势，快速上升的痛点标红。|聚类点击查看代表评价并自动生成改进建议；我方 vs 竞品痛点并排对比。|
|**高频需求热度榜**|排行列表（环比标记）|用户提及功能需求按热度排序（支持 Disney\+、144Hz、杜比全景声、智能家居联动），近 4 周环比上升的高亮。|需求点击查看提及趋势与代表评价；勾选加入需求池。|
|**热度变化曲线**|趋势折线|单需求/单痛点的提及量时间曲线，标注快速上升拐点。|拐点点击查看触发事件；可与价格/促销时间线叠加。|
|**单条评价下钻**|证据抽屉|评价原文、中文翻译（非中文市场）、AI 标注的产品优点与缺点，作为证据可引用。|复制原文/翻译；加入周报；标记低质评价。|

- **关键交互：**痛点聚类点击 → 自动生成改进建议 → 进入决策看板；我方 vs 竞品痛点并排对比；导出网评分析报告；订阅网评周报。

- **状态与空态：**新市场无评价时显示数据积累引导；翻译失败标注"待翻译"并保留原文；聚类样本不足时标注"样本量低，仅供参考"。

- **AI 能力映射：**差评痛点自动挖掘（导向针对性产品改善）、高频新需求智能捕捉、关注热度变化分析、用户情感分析。

- **数据依赖：**全表网评 QA 域（周度刷新，含多语言）；情感词典与聚类模型持续迭代；核心指标：评分/NPS、负面率、聚类声量与增速、需求热度环比。

- **跳转链：**痛点/需求 → 改进建议 → 决策工作台；热度曲线 → 价格/促销时间线叠加；单条评价 → 对阵证据。

**面向产品经理的任务流：**差评爆发预警 → 聚类归因 → 对比竞品口碑 → 生成改进建议 → 发起新品/在售产品改进决策 → 效果回看。

## 行业技术趋势

**页面目标：**回答"行业技术往哪走、我方是否掉队、下一代产品规划需要什么输入"，为产品路线图提供证据。

**页面结构（自上而下）：**SPEC 趋势追踪 → 技术事件流 → 技术机会点 → 我方技术对标。

|区块|关键组件|内容与数据|交互与下钻|
|---|---|---|---|
|**SPEC 趋势追踪**|趋势折线/分布图|对周期内新上市型号的技术参数做分布与均值分析（Mini\-LED 渗透率、平均峰值亮度、平均分区控光数、刷新率演进、芯片平台分布），观察行业规格升级节奏。|参数维度与时间范围可调；渗透率曲线标注拐点事件。|
|**技术事件流**|事件流列表|聚合 CES/IFA 等展会报道、芯片原厂技术通告、面板行情等情报，标注对电视产品的影响方向。|事件点击查看原文摘要；按影响方向筛选（利好/利空/中性）。|
|**技术机会点**|机会点清单|AI 对比我方在售/规划产品与行业趋势，识别"我方落后于趋势"与"我方领先于趋势"的参数清单，作为技术规划输入。|落后项点击查看差距量化；机会点一键转入决策工作台。|
|**我方技术对标**|对标表|我方各产品线代表机型在关键参数上与行业均值/头部竞品的差距，标注换代窗口建议。|点击进入竞品对阵；生成技术趋势报告。|

- **关键交互：**参数维度选择与时间范围调整；导出趋势分析报告；机会点/落后项一键生成产品规划输入清单。

- **状态与空态：**事件源未收录时显示来源缺口；样本量不足的参数标注"样本少，趋势待确认"；展会季自动高亮事件密度。

- **AI 能力映射：**行业技术趋势 SPEC 自动追踪、市场机会自动识别（基于技术趋势与 SPEC 变化）、竞品新品自动识别。

**数据依赖与任务流：**全表 SPEC 域 \+ 情报类爬取；核心指标：关键参数渗透率、我方领先/落后项清单。任务流：趋势变化 → 机会/风险判定 → 更新产品规划输入 → 纳入新品改进建议。

## 竞品促销活动预测

**页面目标：**回答"竞品下一次促销窗口什么时候、力度多大、我方要不要跟、怎么跟"，把促销预测转化为可执行的应对方案。

**页面结构（自上而下）：**促销历史时间轴 → 促销强度对比 → AI 促销预测 → 我方促销效果对比。

|区块|关键组件|内容与数据|交互与下钻|
|---|---|---|---|
|**促销历史时间轴**|时间轴组件|竞品与我方历史促销记录（时间、渠道、类型：直降/买赠/以旧换新/补贴、让利幅度）。|点击促销查看明细与同期效果；按品牌/渠道筛选。|
|**促销强度对比**|象限矩阵|促销频率 × 让利力度的象限对比，识别激进/稳健促销者。|点击品牌点查看历史促销组合；识别与我方正面冲突窗口。|
|**AI 促销预测**|预测视图（置信区间）|基于历史节奏与渠道大促日历（Prime Day、黑五、区域大促），预测未来 4—8 周竞品促销窗口与预计幅度，给出置信度与假设说明。|查看预测依据（假设列表）；应对策略建议（跟价/错位促销/主推其他卖点）；订阅促销预警。|
|**我方促销效果对比**|对比表|同窗口期我方促销投入产出对比，支撑应对决策与复盘。|按促销类型对比 ROI；导出复盘报告。|

- **关键交互：**预测解释（查看预测依据）；应对策略建议（跟价/错位促销/主推其他卖点）；订阅促销预警；预测结果一键转入决策审批。

- **状态与空态：**预测数据不足时下调置信度并说明缺口；大促日历未配置时提示补充；历史记录缺失标注空白期。

- **AI 能力映射：**促销活动自动识别（竞品与我方）、竞品定价策略分析、趋势预测。

- **数据依赖：**全表价格域中的促销记录 \+ 渠道大促日历；核心指标：预测窗口命中率、让利幅度预测偏差。

**面向产品经理的任务流：**促销窗口预警 → 查看历史强度与冲突窗口 → 生成应对策略（跟价/错位）→ 发起决策审批 → 效果复盘闭环。

## 产品竞争决策工作台与预警中心

**页面目标：**回答"该做什么决策、理由是什么、谁来做、做没做、有没有效"，把各模块洞察收敛为可跟踪、可留痕、可评估的决策闭环。

**页面结构（自上而下）：**竞争力评价卡 → 市场机会清单 → 新品改进建议清单 → 决策看板 → 效果评估区。

|区块|关键组件|内容与数据|交互与下钻|
|---|---|---|---|
|**竞争力评价卡**|评分卡 \+ 雷达|AI 综合 SPEC、价格、网评自动生成产品竞争力评分与评价总结（一句话结论 \+ 分维度得分与趋势）。|点击维度查看构成；与上期对比；进入对阵分析。|
|**市场机会清单**|机会点列表（优先级）|基于技术趋势、SPEC 变化、促销活动识别的机会点，每条含机会描述、数据依据、优先级。|机会点点击查看依据；一键转为待评估决策。|
|**新品改进建议清单**|建议列表（证据引用）|基于用户网评洞察的建议（如"开机广告可一键关闭"），每条含建议、证据引用（评价/聚类）、优先级。|建议点击查看原始证据；支持编辑建议描述后发起决策。|
|**决策看板**|看板（状态流转）|建议与决策按"待评估 → 已采纳 → 实施中 → 已完成"流转，指定责任人、跟踪进度、效果回看，形成留痕。|新建决策；指派责任人并通知；状态推进；驳回记录原因；截止时间与 SLA。|
|**效果评估区**|统计卡|AI 分析被采纳率、人工抽检准确率、预警命中率月度统计。|点击进入效果评估看板；不达标能力进入模型优化队列。|

- **关键交互：**一键生成决策简报；指派责任人并通知；效果回看；决策支持导出/归档。

- **状态与空态：**无待评估项时显示空态引导；决策逾期自动高亮并提醒；证据缺失的决策标注"证据不足，需补充"。

- **AI 能力映射：**产品竞争力自动评价、市场机会自动识别、新品改进建议、定价异常监测、全球价格监测。

- **数据依赖：**全部数据域 \+ 决策留痕记录（责任人/时间/状态）；核心指标：决策采纳率、闭环完成率、抽检准确率。

- **跳转链：**机会/建议 → 决策详情；决策详情 → 证据抽屉；效果评估 → 模型优化队列。

**预警中心（贯穿性支撑模块）：**跨模块聚合价格异常、新品认证、差评爆发、促销启动、趋势突变等预警；按严重度分级（高/中/低）；状态流转为"发现 → 归因 → 指派 → 跟踪 → 关闭"。归因视图以事件标注 \+ 同期对比沉淀归因结论；支持批量指派与关闭，关闭时必填结论供复盘。

**面向总经理的任务流：**查看待审批决策与高优先级预警 → 查看 AI 简报与证据 → 通过/驳回/指派 → 跟踪实施与效果回看。**面向产品经理：**发起建议 → 提交审批 → 实施跟踪 → 效果评估。

## 核心页面线框示意

**五组线框**覆盖十一个核心页面：①运营总览、竞品对阵；②价格监控、新品预警；③网评监测、竞争决策；④汇总运营总界面四页（全球运营总览、跨产品线对标矩阵、全球价格矩阵、组合与资源分配）；⑤分析工作台首页、决策审批队列、预警详情、数据健康台。线框为结构示意（非高保真），标注数字为占位示例，落地以实际数据为准。

线框要点：每个页面均为"筛选条 \+ 洞察视图 \+ 证据明细 \+ 决策动作"的组合；AI 结论默认完整可见，hover/点击只补充细节；异常信息必须可见、可查、可指派；汇总与支撑页面同样遵循三角色任务模型（总经理看结论、产品经理做分析、汇总界面做对标）。

# 三角色界面定位与权限

## 产品线总经理：一屏决策

**角色任务模型：**总经理每天的核心动作是"看结论 → 处置异常 → 拍板 → 派活 → 回看"，界面按此组织，所有分析细节折叠、仅按需展开。

**专属页面清单：**

|页面|默认数据|页面承载与关键操作|
|---|---|---|
|**运营总览（默认首页）**|本产品线 · 本周 · 本区域|KPI 红绿灯、AI 洞察列表、预警聚合条、竞品动态时间线、决策入口；操作：看结论、处置预警、订阅日报/周报（详见 3\.1）。|
|**决策审批队列**|待我审批 · 按紧急度排序|每条决策含 AI 简报、证据摘要、责任人、SLA 倒计时；操作：通过并下发 / 驳回并评论 / 转他人研判；效果回看（采纳率/闭环率/命中率）。|
|**预警中心**|高/中/低 · 全部数据域|跨模块聚合与分级；操作：查看归因、一键指派、跟踪处置、关闭留痕。|
|**订阅管理**|默认日报|配置日报/周报/实时推送的频次与渠道（飞书消息/邮件）；周报默认含竞品动态与对阵摘要。|
|**竞争决策看板（只读）**|本产品线全部决策|决策状态分布、实施进度、效果回看；操作：下钻到单条决策证据，不承担编辑。|

**日常任务流：**晨间：打开运营总览 → 处理高优先级预警（归因已由 AI 完成）→ 审批决策队列（通过/驳回）→ 指派待办 → 晚间回看实施进度；周报自动生成并推送，异常周自动加注重点。

## 产品经理：分析工作台

**角色任务模型：**产品经理是**单线级唯一可写角色**（分析、建议、维护类写操作），核心动作是"承接线索 → 深度分析 → 形成建议 → 发起决策 → 跟踪闭环"，工作台为其整合全部下钻、筛选、标注与导出能力。**可写边界口径：**汇总运营总界面（Portal）仅做跨线下发与跟踪（下发物进入目标线审批队列），不直接写入线级数据；审批动作在线级由产品线总经理完成，Portal 侧只读\+催办；汇总级资源审批归属与多级流程见 8\.2 待确认事项。

**专属页面清单：**

|页面|默认数据|页面承载与关键操作|
|---|---|---|
|**分析工作台首页**|我的待办 \+ 全部线索池|待办（承接预警/指派）、线索池（按置信度排序的 AI 发现）、我的分析草稿；操作：领取线索、开始分析、新建草稿。|
|**竞品对阵分析**|本线主力机型对阵|SPEC 对比、雷达、卖点提取、三栏结论；操作：建对阵、参数溯源、导出对阵报告（详见 3\.2）。|
|**价格策略监控**|本线价格带 · 周度|趋势、渠道比对、策略分析、预测；操作：调整预测参数、标记异常、生成跟价建议（详见 3\.3）。|
|**新品预警研判**|关注品牌新认证|预警卡片、上市窗口、冲击评估；操作：配置预警规则、威胁评估、发起应对建议（详见 3\.4）。|
|**网评与需求分析**|本线机型网评|聚类、热度、单条下钻；操作：聚类生成改进建议、需求入池、导出报告（详见 3\.5）。|
|**决策发起与跟踪**|我发起的决策|决策看板（编辑态）；操作：新建决策、提交审批、实施跟踪、效果回看。|
|**数据健康台**|全部数据域|爬虫状态、数据新鲜度、质量问题（归一化缺失、区域缺失）；操作：发起数据修复、维护归一化映射。|

**日常任务流：**打开工作台首页 → 领取高置信度线索 → 进入对应模块分析（调整参数/筛选/下钻证据）→ 形成建议（AI 草稿 \+ 人工修订）→ 提交审批 → 跟踪实施与效果；每周对线索池做一次复盘，标记误报反馈模型优化。

## 汇总运营总界面：对标与组合

**角色任务模型：**汇总运营总界面面向跨产品线统筹者，核心动作是"横向对标 → 发现强弱线 → 组合与资源分配 → 下钻单线验证"。默认"全球 \+ 全部产品线"，任意指标可排序并下钻回到单线总览与工作台，不重复建设单线明细。

**专属页面清单（四页）：**

# AI 交互设计规范

## AI 洞察卡片：现象—证据—建议—置信度—溯源

平台所有 AI 结论统一采用五要素卡片呈现，保证结论"可信、可查、可行动"。

|要素|规范与示例|
|---|---|
|**现象**|一句话结论，主谓宾完整。示例："TCL 55Q 系列均价周降 8%，逼近我方价格带"。|
|**证据**|结论依赖的数据摘要与时间范围。示例："AM 五渠道 09\-22 至 09\-28 价格记录"。|
|**建议**|可执行动作与优先级。示例："建议评估跟价或错位促销，72 小时内完成研判"。|
|**置信度**|AI 置信度百分比与主要不确定点（数据缺失、翻译偏差等）。|
|**溯源**|"查看证据"按钮，直达明细层（价格记录表、评价原文、认证记录）。|

交互规则：卡片默认折叠为三行，点击展开证据与建议；支持"已读"与"不再推荐同类"反馈；误报可由产品经理标记，进入效果评估样本。

## AI 对话助手

**入口与能力：**全局右上角常驻入口，支持自然语言查询与问数，如"TCL 最近三个月降价策略是什么""U9N 差评集中在哪""下个月竞品会促销吗"。助手返回结论 \+ 证据摘要 \+ "直达模块"按钮，所有回答标注数据时间范围与口径；复杂问题引导到对应模块的完整分析视图，不在对话中堆砌长文。

**角色化默认：**按当前角色预置问题与话术——总经理常问"今天要处理什么""这个建议依据是什么"；产品经理常问"这个痛点怎么改进""预测参数怎么调"；汇总运营常问"哪条线最弱""资源往哪投"。回答遵循五要素卡片规范（现象/证据/建议/置信度/溯源），支持追问与多轮澄清。

## 预警中心：发现—归因—指派—跟踪—关闭

预警触发规则示例（落地前与业务对齐阈值）：

- **高：**竞品价格突降超过 10%；FCC/能效库检出竞品新认证；某聚类负面声量两周翻倍。

- **中：**竞品促销启动；同型号渠道价差超过 8%；热度需求环比上升超 30%。

- **低：**情报库例行更新；参数/价格小幅波动。

每条预警含影响面（涉及产品线、区域、价格带）与归因结论；支持一键指派、通知触达与处置状态跟踪，关闭时记录结论供复盘。

## 订阅与推送

支持日报（价格/网评/预警摘要）、周报（竞品动态与对阵摘要）、实时推送（高严重度预警）；触达渠道为飞书消息与邮件；订阅配置按角色默认预置（总经理日报、产品经理实时），可自定义。

## 效果评估机制

对应 AI 能力规划技术点 3，界面内置效果评估看板：人工抽检准确率（随机抽样复核 AI 结论）、决策采纳率（改进建议被采纳比例）、预警命中率（实际发生/预警数）。每月汇总，指标不达标的能力进入模型优化队列。

**入口与范围：**顶部导航常驻搜索框；支持按型号（如 U9N）、品牌、竞品事件、预警、决策、规格参数、用户需求关键词检索；结果按"型号/事件/预警/决策/文档"分组展示，命中即跳转对应页面并自动带入筛选条件。

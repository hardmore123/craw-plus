# 交接文档汇总 · 阅读指南

本文件夹把整个项目**用于交接阅读的说明文档、清单明细、工作日志、历史报告**统一归集到一处，
便于交接者一站式查阅，不必在 01/03/06/09 等多个目录间来回找。

> ⚠️ **本文件夹是「只读汇总副本」**，便于阅读交接。**实际运行与改代码仍在 `01_项目代码/`**，
> 数据库与代码改动以 `01_项目代码/` 里的为准（那里随 git 版本管理）。本文件夹里的同名文件是其副本。
> 凡标「★权威」的文档是当前可依据的；标「历史」的是旧版，仅供追溯，勿作当前依据。

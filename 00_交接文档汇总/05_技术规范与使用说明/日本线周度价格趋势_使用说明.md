# 日本线周度价格趋势曲线 —— 使用说明

监控日本线（kakaku.com 価格.com）每个产品在各渠道下的价格，按**周度**生成价格趋势曲线。
覆盖 6 品牌：Hisense / SONY / REGZA / Panasonic / TCL / SHARP。
8 个渠道：エディオン/ヨドバシ/ヤマダ/ビックカメラ/ケーズデンキ/Joshin/ノジマ/Amazon。

## 交付物三件套

| 形式 | 脚本/端点 | 输出 |
|---|---|---|
| HTML 报告（内嵌 SVG 折线图） | `scripts/gen_jp_price_trend_html.py` | `data/价格趋势_日本_kakaku_*.html` |
| Excel 图表（原生折线图） | `scripts/gen_jp_price_trend_xlsx.py` | `data/价格趋势_日本_kakaku_*.xlsx` |
| API 端点（JSON 时序） | `GET /api/prices/weekly` | 见下 |

## 数据基础

- 表：`price_shop_snapshot`（product_id × shop × price × captured_at，只 INSERT 不覆盖 = 天然时序）
- 周度聚合：`db.weekly_price_series()` 按 `strftime('%Y-W%W', captured_at)` 取每周每渠道最后一次报价

## 快速开始

### 1. 每周采集（积累曲线数据）
```bash
# 手动跑一次（抓全部 6 品牌入库）
python scripts/weekly_kakaku_price.py

# 冒烟测试（每品牌只抓 2 个机型，不实际抓站）
python scripts/weekly_kakaku_price.py --dry-run --brand hisense_jp --limit-models 2

# 只抓指定品牌
python scripts/weekly_kakaku_price.py --brand hisense_jp --brand sony_jp
```

定时调度：导入 `deploy/kakaku_weekly_task.xml` 到 Windows 任务计划程序（每周一 09:00 自动执行）。
```powershell
Register-ScheduledTask -Xml (Get-Content "deploy\kakaku_weekly_task.xml" -Raw) `
  -TaskName "KakakuWeeklyPrice" -User "SYSTEM" -Force
```

### 2. 生成 HTML 报告
```bash
# 全部品牌
python scripts/gen_jp_price_trend_html.py

# 单品牌
python scripts/gen_jp_price_trend_html.py --brand hisense_jp

# 最近 12 周
python scripts/gen_jp_price_trend_html.py --weeks 12
```
双击打开生成的 `.html` 即可查看：每个产品一张折线图，X 轴=周次，Y 轴=JPY，每渠道一条线，
悬停显示渠道中文名/价格/周次。

### 3. 生成 Excel 图表
```bash
# 全部品牌（每品牌一个 sheet，每产品嵌一张原生折线图）
python scripts/gen_jp_price_trend_xlsx.py

# 单品牌
python scripts/gen_jp_price_trend_xlsx.py --brand hisense_jp

# 最近 12 周
python scripts/gen_jp_price_trend_xlsx.py --weeks 12
```
> 依赖 openpyxl（requirements.txt 可选依赖）。若当前环境未装，可借用已有 openpyxl 的
> Python 环境运行，例如：
> `"C:\...\marker-master\.venv\Scripts\python.exe" scripts/gen_jp_price_trend_xlsx.py`

### 4. 调用 API
```bash
# 启动后端
python -m overseas.api.server --port 8000 --db data/overseas.db

# 查询全部品牌周度趋势
curl "http://127.0.0.1:8000/api/prices/weekly?weeks=12&region=jp"

# 查询单品牌
curl "http://127.0.0.1:8000/api/prices/weekly?brand=hisense_jp&weeks=12&region=jp"
```
返回结构：
```json
{
  "weeks": ["2026-W36", "2026-W37", ...],
  "products": [
    {
      "product_id": 6, "brand": "Hisense", "model": "65U8S", "size": "65\"",
      "shops": [
        {"shop": "エディオンネットショップ",
         "series": [{"week": "2026-W36", "price": 220000, "is_lowest": false}, ...]}
      ]
    }
  ]
}
```
